MARLEY News¶

MARLEY v2¶

Published by Steven Gardiner on 2026-08-01 15:11:00

I am pleased to announce version 2.0.0 of MARLEY, the first official update to the code since November 2023. This major release implements an improved model of the νe-40Ar\nu_e\text{-}^{40}\mathrm{Ar}νe​-40Ar charged-current cross section that is described in arXiv:2604.26801 [hep-ph]. The previous MARLEY output format has been entirely replaced by the HepMC3 event record. The representation of neutrino interactions within HepMC3 data structures follows the recommendations of version 1.0.0 of the NuHepMC standard.
