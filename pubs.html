MARLEY Bibliography¶

This bibliography attempts to collect a full list of publications in three categories:

  1. References discussing MARLEY itself

  2. Publications that directly use MARLEY in some way, e.g., experimental sensitivity studies based upon MARLEY simulations

  3. Publications that refer to MARLEY predictions without running the code directly

User contributions to this list are strongly encouraged. If you have written a publication, thesis, etc. in which MARLEY is used, please send me a citation (BibTeX format preferred) to advertise on this page.
